# 项目初始化提示词（新项目冷启动）

> 场景：新业务项目刚跑完 `bash .pact/scripts/init.sh`，第一次打开 coding agent 时使用。
> 把「提示词」一节整段复制进对话，替换 `<尖括号>` 内容。

---

## 提示词

```text
请先读取项目根目录下的 PACT.md。本项目采用 PACT：产品 AI 契约化交付流程。

【项目背景】
- 项目名称：<项目名>
- 一句话定位：<这个产品做什么>
- 目标用户：<谁在用，什么场景>
- 核心目标：<上线后要验证/达成的一件事>
- 终端形态：<Web 后台 / 移动 H5 / 微信小程序 / 多端>
- MVP 范围倾向：<目前想到必须做的功能，列 3-5 条即可，没有就说"待讨论">

【你的任务】
1. 读取 PACT.md，确认本项目目录约定与执行规则。
2. 根据上述背景，生成 07-其他文档/项目背景_v1.0.md，内容包括：
   - 项目定位与目标用户
   - 核心业务流程（文字描述即可）
   - 终端形态与技术栈倾向
   - MVP 范围（做什么 / 明确不做什么）
   - 待确认问题清单（列出你判断需要我拍板的问题）
3. 基于背景生成 02-产品文档/项目_PRD_v0.1.md 骨架：
   - 只搭结构（背景、用户与场景、功能需求、页面清单、验收标准、版本规划），
     内容按现有信息填充，缺失处标注「待补充」。
4. 输出就绪报告：当前所处 PACT 阶段、已生成文件清单、下一个任务建议
   （按 PACT 门禁，下一步应是「补全 PRD → 页面清单 → 验收清单」）。

【约束】
- 本次任务只做初始化，不写任何代码。
- 没有更新需求契约、UIUX 契约或 API 契约前，不修改 06-项目编码/。
- 信息不足时先列入「待确认问题清单」，不要自行编造业务细节。
```

---

## agent 正常应产出

```text
07-其他文档/项目背景_v1.0.md        ← 项目背景与待确认问题
02-产品文档/项目_PRD_v0.1.md        ← PRD 骨架（待补充项已标注）
就绪报告                            ← 当前阶段 + 下一步任务建议
```

## 就绪后的第二个任务（示例）

```text
请读取 02-产品文档/项目_PRD_v0.1.md 和 07-其他文档/项目背景_v1.0.md，
补全 PRD 至 v1.0（解决待确认问题清单里我逐条回复的结论），
并生成 02-产品文档/页面清单_v1.0.md 和 02-产品文档/验收清单_v1.0.md。
```

之后按 PACT README 5.4 的任务序列继续：页面设计契约 → API 契约 → Mock → 后端 → 联调。
