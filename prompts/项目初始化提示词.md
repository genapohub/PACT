# 项目初始化提示词（新项目冷启动）

> 前置：业务项目根目录已执行 `git clone git@github.com:genapohub/PACT.git .pact`。
> 使用：把「提示词」一节整段复制进 coding agent（Claude Code / Codex / Cursor / Trae 等）对话，替换 `<尖括号>` 内容。
> agent 会自动完成：建目录 → 复制模板 → 屏蔽 .pact → 生成项目背景与 PRD 骨架 → 输出就绪报告。

---

## 提示词

```text
请读取项目根目录下的 .pact/ 目录。这是 PACT：产品 AI 契约化交付流程的规范仓库。
本项目采用 PACT 流程开发，本次任务：初始化项目。

【项目背景】
- 项目名称：<项目名>
- 一句话定位：<这个产品做什么>
- 目标用户：<谁在用，什么场景>
- 核心目标：<上线后要验证/达成的一件事>
- 终端形态：<Web 后台 / 移动 H5 / 微信小程序 / 多端>
- MVP 范围倾向：<目前想到必须做的功能，3-5 条即可，没有就写"待讨论">

【第一步：初始化项目结构（按 .pact 规范执行）】
1. 创建 7 个标准目录（已存在则跳过）：
   01-竞品分析、02-产品文档、03-品牌设计、04-UIUX设计、05-技术文档、06-项目编码、07-其他文档
2. 复制模板到对应位置（不覆盖已有文件）：
   - .pact/templates/PACT项目说明模板.md   → 根目录 PACT.md
   - .pact/templates/DESIGN.md模板.md      → 根目录 DESIGN.md
   - .pact/templates/验收清单模板.md        → 02-产品文档/验收清单_v1.0.md
   - .pact/templates/页面设计契约模板.md    → 04-UIUX设计/页面设计契约_v1.0.md
   - .pact/templates/API接口契约模板.md     → 05-技术文档/API接口契约_v1.0.md
   - .pact/templates/联调记录模板.md        → 05-技术文档/联调记录.md
3. 把 .pact/ 写入项目根目录 .gitignore（规范仓库只在本地引用，不入业务仓库）。

【第二步：初始化项目背景】
读取刚生成的根目录 PACT.md，确认目录约定与执行规则，然后：
1. 生成 07-其他文档/项目背景_v1.0.md，内容包括：
   - 项目定位与目标用户
   - 核心业务流程（文字描述即可）
   - 终端形态与技术栈倾向
   - MVP 范围（做什么 / 明确不做什么）
   - 待确认问题清单（列出你判断需要我拍板的问题）
2. 基于背景生成 02-产品文档/项目_PRD_v0.1.md 骨架：
   - 只搭结构（背景、用户与场景、功能需求、页面清单、验收标准、版本规划），
     内容按现有信息填充，缺失处标注「待补充」。

【输出】
就绪报告：已完成动作清单、当前所处 PACT 阶段、下一个任务建议
（按 PACT 门禁，下一步应是「补全 PRD → 页面清单 → 验收清单」）。

【约束】
- 本次任务只做初始化，不写任何代码。
- 信息不足时列入「待确认问题清单」，不要自行编造业务细节。
- 之后的每次对话，先读取根目录 PACT.md 再工作；
  在没有更新需求契约、UIUX 契约或 API 契约前，不要直接修改代码。
```

---

## agent 正常应产出

```text
PACT.md / DESIGN.md                  ← 根目录（从模板复制）
01-竞品分析/ … 07-其他文档/           ← 7 个标准目录
.gitignore（含 .pact/）              ← 规范仓库不入业务仓库
07-其他文档/项目背景_v1.0.md          ← 项目背景与待确认问题
02-产品文档/项目_PRD_v0.1.md          ← PRD 骨架（待补充项已标注）
就绪报告                             ← 当前阶段 + 下一步任务建议
```

## 就绪后的第二个任务（示例）

```text
请读取根目录 PACT.md、02-产品文档/项目_PRD_v0.1.md 和 07-其他文档/项目背景_v1.0.md，
补全 PRD 至 v1.0（待确认问题清单我逐条回复结论），并生成
02-产品文档/页面清单_v1.0.md 和 02-产品文档/验收清单_v1.0.md。
```

之后按 PACT README 5.4 的任务序列继续：页面设计契约 → API 契约 → Mock → 后端 → 联调。
